# Module 06 — Contribution Highlighter

## Responsibilities
- Locate the explicit contributions of the paper  
- Summarize as 3–6 bullet points  

---

## Workflow
1. Search for contribution indicators:  
   - “We propose…”  
   - “Our main contribution…”  
   - “This paper presents…”  
2. Extract the contribution text  
3. Summarize into bullet form  
4. Return list to Rendering Module  

---

## Guardrails
- Must use only contributions written in the paper  
- If not clearly stated:  
  “The paper does not explicitly state its main contributions.”
