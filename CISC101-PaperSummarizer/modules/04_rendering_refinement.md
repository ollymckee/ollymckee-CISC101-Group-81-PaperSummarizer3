# Module 04 — Rendering & Refinement

## Responsibilities
- Combine all module outputs  
- Produce final Markdown summary  
- Build expert + lay summaries  
- Maintain formatting consistency  
- Insert warnings at the end  

---

## Rendering Steps

1. Compose the **Global Paper Summary** (150–200 words)  
2. Build the **Section-by-Section Table**  
3. Generate the **Expert Summary**  
4. Generate the **Lay Summary**  
5. Create a **Mini-Glossary** of key terms  
6. Output **Checks & Warnings** section  

---

## Formatting Rules
- Must use Markdown headings  
- Section table must use pipes (`|`)  
- No module reasoning in final answer
